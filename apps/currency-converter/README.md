# Currency Converter Mini-App

A live foreign exchange rate converter built with vanilla JavaScript, the ExchangeRate REST API, and dynamic country flag integrations.

## Features
- **Real-Time Exchange Rates**: Fetches live currency conversion pairs using the ExchangeRate-API.
- **Dynamic Flag Integration**: Automatically updates country flag icons via FlagsAPI.
- **Currency Swapping**: Quick swap button with 180-degree rotation animation.
- **Offline Fallback Dataset**: Bundles `data.json` with 150+ full currency name mappings.

## Tech Stack
- HTML5, CSS3
- Vanilla JavaScript (ES6+ `fetch`, DOM updates)
- ExchangeRate API & FlagsAPI
- Bootstrap 5

## How to Run
Open `index.html` in any browser or with VS Code Live Server.
