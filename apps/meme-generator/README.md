# Meme Generator Mini-App

A client-side JavaScript mini-application that interfaces with the Imgflip public REST API to query and dynamically render top trending meme templates by index.

## Features
- **Asynchronous REST API Integration**: Consumes live meme template endpoints from Imgflip.
- **Dynamic DOM Rendering**: Replaces and mounts images, captions, and responsive containers on demand.
- **Client-Side Input Validation**: Validates 0–99 bounds with helpful error prompts.

## Tech Stack
- HTML5, CSS3
- Vanilla JavaScript (ES6+ `fetch`, async handling)
- Bootstrap 5

## How to Run
Open `index.html` in any web browser or launch with Live Server.
