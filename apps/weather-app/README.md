# Weather Dashboard Mini-App

A dynamic atmospheric conditions dashboard combining OpenWeatherMap API, TimeZoneDB API, and Unsplash contextual city photography.

## Features
- **Multi-API Orchestration**: Combines OpenWeatherMap, TimeZoneDB, and Unsplash APIs.
- **Atmospheric Metrics**: Wind speed, relative humidity percentage, and barometric pressure.
- **Contextual City Photography**: Fetches dynamic high-resolution city backdrops matching search terms.
- **Local Time Calculation**: Determines accurate local time and timezone abbreviations.

## Tech Stack
- HTML5, CSS3
- Vanilla JavaScript (Async/Await, Promises)
- OpenWeatherMap API, TimeZoneDB API, Unsplash API
- Bootstrap 5

## How to Run
Open `index.html` in any browser or launch via VS Code Live Server.
