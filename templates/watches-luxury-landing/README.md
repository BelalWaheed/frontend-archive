# Luxury Timepiece Boutique Landing Page

A responsive product landing page template for luxury timepieces and horology brands built with Bootstrap 5 and customized CSS.

## Features
- **Modern Dark-Mode Palette**: Clean OKLCH-aligned dark slate visual hierarchy.
- **Product Showcase Grid**: Card grid with hover elevation and specifications triggers.
- **Editorial Visual Gallery**: Image grid with transform scale micro-interactions.
- **Full Responsiveness**: Mobile hamburger navigation and fluid column scaling.

## Tech Stack
- HTML5, CSS3
- Bootstrap 5
- Unsplash Photography Assets

## How to Run
Open `index.html` in any web browser.
