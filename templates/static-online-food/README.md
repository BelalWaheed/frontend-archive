# FreshBite Organic Food Delivery Multi-Page Template

A responsive multi-page static website template for an artisan organic food and meal delivery brand.

## Pages
- `index.html`: Hero banner, value propositions, and featured categories.
- `products.html`: Searchable catalog with meal cards and prices.
- `about.html`: Brand story, mission, and regenerative farm partnerships.
- `contact.html`: Interactive order inquiry form with input floating labels.

## Tech Stack
- HTML5, CSS3
- Bootstrap 5
- Unsplash Gourmet Photography

## How to Run
Open any `.html` page in your browser or serve using Live Server.
